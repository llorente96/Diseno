## Ponytail: según el día

Por defecto está **apagado**: el trabajo de Rubén es sobre todo creativo, y `wp-betheme-wpbakery` ya prioriza las opciones del builder antes que el código.

Si toca una temporada con mucho código (CSS, snippets, ajustes de WordPress), actívalo:

```bash
claude plugin enable ponytail@ponytail --scope user
```

Con Ponytail activo, di "stop ponytail" al empezar una sesión de ideas o de dirección de arte, para que no recorte propuestas.

Para volver a apagarlo:

```bash
claude plugin disable ponytail@ponytail --scope user
```
