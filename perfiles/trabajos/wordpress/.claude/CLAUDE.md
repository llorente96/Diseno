## Trabajo: WordPress

- Maquetar un diseño en Betheme o WPBakery: usa la skill `wp-betheme-wpbakery`. Primero opciones del builder; CSS solo si hace falta.
- Desarrollo de plugins o temas: skills de WordPress Dev Skills (activas solo en este proyecto).
- Nunca se edita el tema padre: tema hijo o CSS personalizado del tema.
- Antes de tocar una web en producción, confirma con la persona. Si hay un servidor MCP de la web (p. ej. woodmart), úsalo en vez de pedir capturas.
