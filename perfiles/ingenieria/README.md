# Perfil: Ingeniería

Diseño (sin Adobe) + backend (Perl, Laravel, PHP/WordPress) + automatizaciones n8n.

**Base:** Impeccable + skills del equipo + **Ponytail** + **ECC (selección, en `.claude/`)**

**Plugins:** `design`, `canva`, `figma`, `frontend-design`, `wordpress-devkit`, Samautomation Workflows (n8n)

**Conectores:** Canva, Figma, Magnific, Higgsfield, Google Drive, n8n, GitHub

**No instalar:** Adobe, Superpowers (choca con Ponytail y se solapa con ECC), `social-media-skills`, `marketing`

## Selección de ECC incluida en `.claude/`

Selección de [ECC](https://github.com/affaan-m/ECC) v2.2.3 (licencia MIT, ver `.claude/ECC-LICENSE`). Solo Markdown: sin hooks, sin scripts, sin agentes.

- **Skills (17):** perl-patterns, perl-security, perl-testing, laravel-patterns, laravel-security, laravel-tdd, laravel-verification, backend-patterns, api-design, database-migrations, mysql-patterns, security-review, tdd-workflow, verification-loop, coding-standards, frontend-patterns, frontend-a11y
- **Reglas** (`.claude/rules/ecc/`): common, php, perl, web

Quitados a propósito: `hooks.md` y `common/agents.md`, que remiten a hooks y agentes de ECC no incluidos. `tdd-workflow` menciona `scripts/setup-package-manager.js`, que no se copia: ignóralo.

Uso:

```bash
cp -r perfiles/ingenieria/.claude /ruta/a/tu-proyecto/
```
